Guide de l'enseignant·e et du personnel — créer, faire passer et corriger un examen sécurisé

Ce guide explique, étape par étape :

  • à quoi sert le logiciel et comment il protège l'examen ;
  • le panneau enseignant et toutes ses fonctions ;
  • comment créer un examen (formulaire, rédaction ou document PDF/Word) ;
  • comment le tester en se mettant à la place d'un élève ;
  • comment surveiller en direct, répondre aux demandes d'aide, corriger et exporter.

1. Comprendre MonExamEnLigne en 2 minutes

MonExamEnLigne est la plateforme d'examens du Collège Champagneur. L'enseignant·e prépare l'examen sur le site web ; l'élève le passe soit dans un navigateur, soit — recommandé — dans l'application Windows MonExamEnLigne installée sur les postes de l'école, qui verrouille l'ordinateur pendant l'examen.

Un code, pas de compte élève

Chaque examen reçoit un code à 6 caractères (ex. BC2PXU). L'élève entre le code, son nom et, si demandé, son matricule. Aucun compte à créer.

Environnement contrôlé

Plein écran obligatoire, sorties de l'examen détectées et comptées, copier-coller externe bloqué, applications interdites (Teams, Edge, Chrome…) fermées avant de commencer.

Outils d'aide choisis par vous

Antidote, WordQ, Lexibar (logiciels installés) et Usito, WordReference (en ligne) : vous cochez ceux qui sont permis ; l'élève n'a accès qu'à ceux-là.

Sauvegarde continue

Les réponses sont enregistrées automatiquement toutes les quelques secondes. En cas de panne ou de fermeture, l'élève se reconnecte avec le même code et le même nom et reprend où il était.

Surveillance en direct

Vous voyez chaque copie progresser, les signalements, les collages suspects ; vous pouvez envoyer un message, mettre en pause, bloquer, débloquer, ajouter du temps.

Correction intégrée

Choix multiples corrigés automatiquement, grille de points par question, commentaires, exports PDF et Word (par copie ou toutes les copies), statistiques par question.

Trois types d'examen Formulaire (questions comme Microsoft Forms), Rédaction (un sujet + un éditeur de texte de type Word) et Document téléversé (votre PDF ou Word affiché à l'élève avec une zone de réponse ou des questions).

2. Se connecter et gérer son profil

  1. Ouvrez le site examen.votredomaine et cliquez sur Espace enseignant (en bas de la page d'accueil).
  2. Entrez le courriel et le mot de passe reçus de l'administrateur. À la première connexion, le logiciel vous oblige à choisir un nouveau mot de passe.
  3. Mot de passe oublié ? Demandez à l'administrateur une réinitialisation : vous recevrez un courriel avec un mot de passe temporaire.

Mon profil (icône en haut à droite)

  • Nom affiché : c'est le nom que voient les élèves (« Enseignant : … ») quand l'examen est lié à une liste de classe.
  • Alertes d'aide dans Teams / par courriel : collez l'adresse courriel de votre canal Teams (voir section 10) et cochez si vous voulez aussi recevoir l'alerte à votre courriel. Le bouton Envoyer un test vérifie que tout fonctionne.
  • Sonnerie des alertes d'aide : téléversez votre propre son (MP3, WAV ou OGG, 2 Mo max) ou gardez celle de l'école. Écouter la fait jouer.

3. Le tableau de bord enseignant

C'est la page d'accueil après la connexion. En haut : le menu Tableau de bord, Classes et, pour l'administrateur, Comptes. À droite : la cloche des demandes d'aide et votre profil.

ÉlémentÀ quoi ça sert
CompteursNombre d'examens, d'examens ouverts et d'élèves en cours.
Bandeau « En pause »Apparaît si un de vos examens est en pause, avec un bouton pour reprendre.
Liste « Mes examens »Une carte par examen : titre, matière, code, statut (Brouillon, Ouvert, Fermé), durée, outils permis.
SuiviOuvre la surveillance en direct et la correction (section 9 et 11).
ModifierRouvre l'éditeur de l'examen.
SupprimerSupprime l'examen et toutes les copies. Pour vider seulement les copies, voir section 12.

Statuts Brouillon : invisible pour les élèves. Ouvert : les élèves peuvent entrer le code. Fermé : plus personne ne peut rejoindre ; les copies restent consultables. Le statut se change dans l'éditeur (liste déroulante en haut) puis Enregistrer.

4. Créer un examen — étape 1 : informations

  1. Cliquez sur Créer un examen.
  2. Titre (ex. « Examen de lecture — Chapitre 3 ») et Matière / groupe (ex. « Français 2e sec. »). La matière sert aussi à classer la banque de questions.
  3. Durée en minutes. 0 = sans limite. Le chronomètre démarre quand l'élève clique « Commencer ».
  4. Consignes pour les élèves : affichées sur l'écran d'accueil de l'examen, avant le départ.
  5. Liste de classe (facultatif) : si vous en choisissez une, seuls les élèves inscrits (nom + matricule) peuvent rejoindre et leur temps supplémentaire est appliqué automatiquement (voir section 13).
  6. Collègues avertis quand un élève demande de l'aide : cochez les surveillant·e·s ou technicien·ne·s qui doivent recevoir les alertes « J'ai besoin d'aide » en plus de vous.

5. Créer un examen — étape 2 : type et contenu

Formulaire

Ajoutez des questions avec les boutons Choix multiple, Réponse courte, Développement. Pour chaque question : l'énoncé, les points, et les flèches pour réordonner.

  • Choix multiple : écrivez les choix, puis cliquez sur le cercle à gauche d'un choix pour le marquer comme bonne réponse (il devient vert avec un ✓). Vous pouvez en marquer plusieurs : l'élève verra alors des cases à cocher. La bonne réponse n'est jamais montrée à l'élève et sert à la correction automatique.
  • Réponse courte / Développement : deux champs supplémentaires — Consignes / précisions (affichées à l'élève sous la question) et Réponse attendue / corrigé (visible seulement par vous au moment de corriger).
  • Importer depuis la banque : réutilisez des questions de vos examens précédents (recherche par texte, type, matière). L'icône signet sur une question l'enregistre explicitement dans la banque.

Rédaction

Écrivez le sujet de la rédaction. L'élève dispose d'un éditeur de texte enrichi (gras, italique, listes, titres) et d'un compteur de mots en direct.

Document téléversé

Téléversez votre PDF ou Word (.docx), 20 Mo max. Choisissez ensuite le mode de réponse :

  • Zone de réponse séparée : le document à gauche, une zone de texte (et des questions facultatives) à droite.
  • Réponse dans le document (PDF seulement) : l'élève écrit directement sur les pages du PDF ; vous récupérez ensuite un « PDF annoté ».
Enregistrez souvent Le bouton Enregistrer en haut à droite sauvegarde l'examen. Le code de l'examen est attribué à la première sauvegarde.

6. Créer un examen — étape 3 : outils et sécurité

7. Tester l'examen comme un élève (aperçu)

Il n'y a pas de mode « aperçu » séparé : vous testez exactement ce que vivra l'élève, en rejoignant l'examen vous-même. Cela prend deux minutes.

  1. Dans l'éditeur, mettez le statut sur Ouvert puis Enregistrer. Notez le code affiché en haut.
  2. Ouvrez une fenêtre de navigation privée (Ctrl+Maj+N dans Edge/Chrome) ou un autre navigateur, allez sur la page d'accueil du site, section Espace élève.
  3. Entrez le code, un nom comme TEST Enseignant (et un matricule si l'examen est lié à une classe : utilisez alors un élève de la liste ou retirez temporairement la classe).
  4. Parcourez l'écran d'accueil (consignes, règles, outils), cliquez Commencer, répondez à quelques questions, essayez un copier-coller externe, quittez le plein écran… et remettez la copie.
  5. Revenez dans votre fenêtre enseignant → Suivi : votre copie de test y apparaît avec son historique de surveillance. Ouvrez-la, vérifiez la correction automatique, l'export PDF.
  6. Supprimez la copie de test avec Supprimer dans le détail de la copie (ou Vider les copies pour tout effacer). L'examen reste intact.
Tester l'application Windows Faites le même test depuis un poste élève avec l'application MonExamEnLigne pour vérifier la détection des logiciels (Antidote, WordQ, Lexibar) et la fermeture des applications interdites. Le PreCheck affiche ✓ ou ✗ pour chaque logiciel permis ; l'administrateur retrouve ces informations dans Comptes → Postes.
Si « Application Windows obligatoire » est coché le test depuis un navigateur sera refusé — c'est normal. Décochez-le le temps du test ou testez depuis un poste équipé.

8. Le jour de l'examen : ce que vit l'élève

  1. L'élève ouvre l'application MonExamEnLigne (icône sur le bureau) ou le site web, entre le code, son nom et au besoin son matricule.
  2. Écran d'accueil : titre, consignes, durée, règles de l'examen et outils permis. Dans l'application Windows, le PreCheck liste les applications interdites ouvertes ; un bouton les ferme toutes. Impossible de commencer tant qu'il en reste.
  3. Il clique Commencer : le chronomètre démarre, l'écran passe en plein écran verrouillé.
  4. Barre du haut : temps restant, état « Enregistré », nombre de signalements, boutons des outils permis, bouton J'ai besoin d'aide et Remettre.
  5. Chaque sortie (changement de fenêtre, sortie du plein écran, collage externe…) affiche un avertissement et compte un signalement. Au seuil, la copie se bloque : l'élève ne peut plus écrire jusqu'à ce que vous le débloquiez.
  6. À la remise, une confirmation demande s'il reste des questions sans réponse, puis l'écran de confirmation de remise avec un numéro de confirmation s'affiche. Le bouton vert ferme l'application (ou ramène à l'accueil sur le web).
Panne, fermeture accidentelle, redémarrage Rien n'est perdu : l'élève se reconnecte avec le même code, le même nom et le même matricule et reprend là où il était ; le temps continue de courir. Si la copie a été remise par erreur, vous pouvez la rouvrir (section 9).

9. Surveiller en direct (page Suivi)

Depuis le tableau de bord, cliquez Suivi. La page se rafraîchit toute seule toutes les 5 secondes.

Vue d'ensemble

  • Compteurs En cours / Bloqué / Remis, code de l'examen, bouton Actualiser.
  • Liste des copies à gauche : nom, matricule, progression (questions répondues ou nombre de mots), signalements, collages suspects, dernière activité. Cliquez sur une copie pour ouvrir son détail à droite.
  • Bandeaux d'alerte : Élèves qui demandent de l'aide (jaune) et Examens bloqués (rouge).
  • Alertes automatiques (notifications en bas à droite) : copie bloquée, collage important (plus de 40 mots d'un coup), nouvelle demande d'aide.

Contrôles pour toute la classe

BoutonEffet
Message à tousAffiche un message sur tous les écrans ; chaque élève doit confirmer sa lecture.
Mettre en pause / ReprendreVoile les écrans, bloque la saisie et arrête le chronomètre (alarme incendie, consigne à donner). Le temps de pause est rendu à la reprise ; aucun signalement n'est compté pendant la pause.
Débloquer tousDébloque d'un coup toutes les copies bloquées.
Outils permis en directChangez les outils d'aide permis pendant l'examen ; les élèves voient la barre se mettre à jour.

Contrôles pour une copie

BoutonEffet
MessageMessage privé affiché sur l'écran de cet élève, avec confirmation de lecture.
BloquerL'élève ne peut plus écrire ; ses réponses sont conservées.
DébloquerPour une copie bloquée (par vous ou par le seuil). Vous pouvez joindre un message que l'élève devra lire. Les signalements peuvent être remis à zéro.
Pause (individuelle)Met un seul élève en pause (sortie aux toilettes, intervention).
Temps supplémentaireAjoute des minutes à cet élève ; permet aussi d'autoriser des outils pour lui seul (ex. WordQ pour un élève avec plan d'intervention).
Rouvrir la copiePour une copie remise : l'élève peut se reconnecter et continuer.
SupprimerSupprime cette copie (par exemple une copie de test).

Lire l'historique d'une copie

Le détail montre les événements horodatés : début, sorties de l'examen, collages (avec le texte collé et le pourcentage déjà présent dans la réponse), outils ouverts, messages lus, pauses, demandes d'aide, vérification du poste (nom de l'ordinateur, logiciels trouvés). Le bouton Rapport de surveillance (PDF) en haut de la page exporte tout cela pour l'ensemble de la classe.

10. Demandes d'aide, sonnerie et Teams

Quand un élève clique J'ai besoin d'aide (avec un motif facultatif : problème technique, question sur une consigne…), vous êtes averti·e de trois façons :

  • Dans le logiciel : la cloche en haut à droite affiche un compteur rouge, une notification apparaît, la sonnerie joue et l'onglet du navigateur clignote « 🙋 (1) … ». Dans la page Suivi, un bandeau jaune liste les demandes.
  • Dans Teams : si vous avez enregistré l'adresse courriel de votre canal Teams dans votre profil, un message arrive dans le canal.
  • Par courriel : si vous avez coché l'option dans votre profil.

Cliquez Pris en charge quand vous allez voir l'élève : la demande disparaît pour tous les destinataires et l'élève voit « Votre enseignant·e a pris votre demande en charge ». L'élève peut aussi annuler sa demande.

Obtenir l'adresse courriel d'un canal Teams

  1. Dans Teams, ouvrez le canal voulu (ex. « Surveillance examens »).
  2. Cliquez sur ⋯ à côté du nom du canal → Obtenir l'adresse de courrier électronique.
  3. Cliquez Copier : l'adresse ressemble à nomducanal.xxxxx@amer.teams.ms.
  4. Collez-la dans votre profil → Enregistrer → Envoyer un test.
Option absente dans Teams ? L'administrateur Microsoft 365 doit activer « Les utilisateurs peuvent envoyer des courriels à une adresse de canal » dans le centre d'administration Teams.

11. Corriger, noter et exporter

  1. Page Suivi → cliquez sur une copie Remise.
  2. Chaque question affiche la réponse de l'élève. Pour les choix multiples avec bonne réponse définie, un badge indique ✓ Bonne réponse, ◐ Partiellement correct ou ✗ Mauvaise réponse et les points sont préremplis. Pour les autres, votre réponse attendue s'affiche en vert pour vous aider.
  3. Saisissez les points et un commentaire par question, puis la note globale et un commentaire général. Cliquez Enregistrer la note.
  4. Exports : PDF et Word (la copie corrigée, avec points et commentaires), PDF annoté pour les documents remplis directement dans le PDF. En haut de la page : Toutes (PDF) / Toutes (Word) pour l'ensemble des copies en un seul fichier (une copie par page).
Mise en page des exports Les questions courtes et leurs réponses ne sont jamais coupées entre deux pages ; les longues réponses sont coupées uniquement entre deux paragraphes.

12. Réutiliser un examen, statistiques et banque de questions

Vider les copies pour une autre passation

Dans la page Suivi, Vider les copies supprime toutes les copies (réponses, notes, historiques) en conservant l'examen, son code et ses réglages. Il faut taper SUPPRIMER pour confirmer ; un avertissement s'affiche si des élèves sont encore en cours.

Exportez d'abord Cette action est définitive. Téléchargez Toutes (PDF) et le Rapport de surveillance avant de vider.

Statistiques par question

Onglet Statistiques par question dans la page Suivi : taux de réussite de chaque question, question la plus difficile et la plus facile, répartition des choix cochés pour les choix multiples (la bonne réponse est marquée ✓). Pour les réponses courtes et développements, le taux suit les points que vous avez attribués.

Banque de questions

Toutes les questions de vos examens enregistrés sont ajoutées automatiquement à votre banque personnelle. Dans l'éditeur, Importer depuis la banque permet de les rechercher et d'en insérer une copie dans le nouvel examen. Vous pouvez retirer une question de la banque (icône poubelle dans la fenêtre) sans toucher aux examens existants.

13. Listes de classe et temps supplémentaire

  1. Menu Classes → Nouvelle classe (ex. « 2e sec. groupe 201 »).
  2. Ajoutez les élèves un à un (nom, matricule, temps supplémentaire en minutes ou en %) ou importez-les en collant une liste.
  3. Dans l'examen, étape 1, choisissez cette liste de classe. Seuls les élèves inscrits pourront rejoindre (nom + matricule), le nom de l'enseignant·e se remplit tout seul et le temps supplémentaire est appliqué automatiquement.
Sans liste de classe l'examen est ouvert à toute personne ayant le code : pratique pour un test rapide, moins pour une évaluation officielle.

14. Pour l'administrateur : comptes, alertes, postes

Le menu Comptes n'est visible que par les comptes administrateurs.

OngletFonctions
ComptesCréer un enseignant (courriel de bienvenue automatique avec mot de passe temporaire), importer plusieurs enseignants d'un coup, réinitialiser un mot de passe, désactiver ou réactiver un compte, nommer un autre administrateur.
Journal d'activitéHistorique des actions administratives et des connexions.
Alertes d'aideSonnerie par défaut de l'école ; chemins des logiciels d'aide (si l'application Windows ne trouve pas Lexibar ou WordQ, collez le chemin complet de l'exécutable) ; surveillants par défaut qui reçoivent toutes les demandes d'aide ; destinataires par examen.

15. Questions fréquentes et dépannage

Un élève dit que son code ne fonctionne pas.
Vérifiez que l'examen est Ouvert (pas Brouillon ni Fermé) et, s'il est lié à une classe, que le nom et le matricule correspondent exactement à la liste.
L'élève a fermé l'application ou l'ordinateur a redémarré.
Il se reconnecte avec le même code, le même nom et le même matricule : il reprend où il était. Si la copie a été remise, utilisez Rouvrir la copie.
La copie d'un élève est bloquée alors qu'il n'a rien fait de mal.
Ouvrez sa copie, lisez l'historique (une fenêtre de mise à jour Windows ou une notification peut provoquer une sortie), puis Débloquer en remettant les signalements à zéro.
Antidote, WordQ ou Lexibar n'apparaît pas pour l'élève.
1) L'outil est-il coché dans l'étape 3 de l'examen ? 2) L'élève est-il dans l'application Windows (les logiciels du poste ne fonctionnent pas depuis un navigateur) ? 3) Le PreCheck affiche-t-il ✗ pour cet outil ? Si oui, l'administrateur peut ajouter le chemin dans Comptes → Alertes d'aide. Pour Antidote, l'option « Agent Connectix » doit être activée dans les réglages d'Antidote sur le poste.
Il faut évacuer la classe ou donner une consigne à tout le monde.
Mettre en pause toute la classe : les écrans se voilent et le chronomètre s'arrête. Reprendre ensuite ; le temps perdu est rendu.
Un élève a droit à du temps supplémentaire ou à un outil particulier.
Inscrivez-le dans la liste de classe avec son temps supplémentaire, ou pendant l'examen, ouvrez sa copie → Temps supplémentaire (vous pouvez aussi y autoriser un outil pour lui seul).
Je dois sortir d'un poste verrouillé par l'application Windows.
Appuyez sur Ctrl+Alt+Maj+U et entrez le code de sortie d'urgence défini à l'étape 3 de l'examen. L'utilisation est consignée dans l'historique.
Je ne reçois pas la sonnerie des demandes d'aide.
Le navigateur ne joue un son qu'après une interaction sur la page : cliquez une fois n'importe où dans la page Suivi après l'avoir ouverte. Vérifiez aussi le volume et, dans votre profil, le bouton Écouter.
Combien d'élèves en même temps ?
Le serveur actuel est prévu pour environ 250 élèves simultanés. Pour un examen de niveau (plusieurs centaines d'élèves), prévenez l'administrateur à l'avance.
